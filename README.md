# Kodi repozitář – Webshare Cinema (upravená verze)

Repozitář doplňků pro Kodi 19+. Obsahuje upravený doplněk **Webshare Cinema** (`plugin.video.wsc`):
nabídka filmů a seriálů z TMDB, hledání a přehrávání z Webshare vlastním účtem, řazení podle jazyka
a kvality, oblíbené, historie a pamatování pozice.

Dále obsahuje doplněk **Titulky.com** (`service.subtitles.titulky.com`, autor Beam) s vypnutým odesíláním
statistik.

Doplněk vychází z YaWSP (cache-sk) a `Mudraon/plugin.video.wsc`, licence AGPL-3.0. Zdrojový kód je
součástí balíčku `.zip`.

## Instalace

1. Stáhnout `repository.stepos/repository.stepos-1.0.0.zip`.
2. V Kodi: Nastavení → Systém → Doplňky → zapnout Neznámé zdroje.
3. Doplňky → Instalovat ze souboru zip → vybrat stažený soubor.
4. Doplňky → Instalovat z repozitáře → Stepos – doplňky → Video doplňky → Webshare Cinema.

Nové verze si pak Kodi stahuje samo. Doplněk neobsahuje žádný obsah ani přihlašovací údaje;
potřebuje vlastní účet na Webshare a vlastní klíč TMDB.
